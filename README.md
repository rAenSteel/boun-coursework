# Boğaziçi CMPE coursework

Selected programming assignments from my Computer Engineering courses at Boğaziçi University, published after grading.

| Folder | Course | What it is |
| --- | --- | --- |
| [cmpe150-jpl-interpreter](cmpe150-jpl-interpreter) | CMPE 150 Introduction to Computing, Fall 2025 (HW5) | A compiler and interpreter for JPL, a small language with Japanese keywords, in plain Python |
| [cmpe150-image-processing](cmpe150-image-processing) | CMPE 150 Introduction to Computing, Fall 2025 (HW6) | Grayscale PGM image transformations and a 3x3 convolution filter, written without any imports |
| [cmpe160-pacman](cmpe160-pacman) | CMPE 160 Object Oriented Programming, Spring 2026 | A Pac-Man clone in Java with three ghost strategies and BFS pathfinding, built on course starter code |

The CMPE 150 assignments were written under course rules that limited the language features we could use: no external libraries, no `try`/`except`, no regular expressions and no `eval`. The code stays within those limits.

If you are taking one of these courses, please write your own solution. The assignments may be reused, and copying them is an academic integrity violation.
